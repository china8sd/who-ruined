# Who Ruined v6.3

Match ID → OpenDota → role-aware match analysis → verdict.

## Что нового в v4.0
- **Ссылка на разбор:** `?match=ID` — открывается и сразу анализируется; адрес обновляется после анализа.
- **Карточка-картинка (PNG)** для шаринга + кнопка копирования текста.
- **История** последних 8 матчей (localStorage).
- **Калибровка по рангу** матча и **поправки по ролям героев** (Support/Carry из constants/heroes).
- **Ливеры/АФК** не выбираются руинером и помечаются.
- **Анализ предметов:** BKB/Aeon к лейту у кора, детекция против невидимости у саппортов.
- **График золота** с метками смертей руинера.
- **Режим «Адвокат»** — сильные стороны и контекст в защиту руинера.
- **RU/EN** переключатель (интерфейс; длинные аналитические тексты остаются на русском).
- **Кэш** констант героев/предметов на 24 ч.
- **Ошибки:** 404 / 429 / 5xx / нет сети; для непарсенных матчей — кнопка «Запросить парсинг».
- Визуальная полировка (стекло, анимации, акценты, мобильная версия).
- Новый файл `js/extras.js` (грузится после `app.js`).
