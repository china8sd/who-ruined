SKIN SPACE & COLLECTORS CACHE — МОБИЛЬНЫЙ БАННЕР

Надпись: «Купи скины по выгодным ценам».
Фон: кометы, звёзды и мягкое свечение. Баннер статичный, без JavaScript.
Весь HTML-баннер ведёт на https://collectorscache.ru/ в новой вкладке.

ДВА ФОРМАТА
1. index.html + style.css + assets/ — адаптивный HTML.
   Высота 105 px, рекомендуемая ширина 320–480 px. Основной макет: 360×105.
2. banner-360x105.webp — готовая статичная картинка 360×105.
   banner-360x105.png — тот же вариант в PNG.
   К картинке нужно добавить ссылку при размещении.
